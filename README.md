# ycsp
面向青少年的 **CSP（晶体结构预测）教学平台**。

> **什么是 CSP？**
> 给定一种物质的化学成分（例如“氯化钠 NaCl”），预测它在常温常压下最可能形成什么样的晶体结构。
> 本项目把这件原本需要专业软件和大量计算的事情，做成一个网页：学生用鼠标点一点，就能观察结构、看到结果，**不需要任何计算或编程基础**。

## 项目定位

- 使用者是青少年学生，默认没有任何计算或编程背景。
- 唯一验收标准：**中学生能否独立看懂并操作**。
- 教学界面不允许出现：未解释的专业术语、黑箱算法、没有反馈的漫长等待；所有报错都要转成学生看得懂的中文提示。

## 整体架构

项目分为三层，每层只负责一类事情，层与层之间通过网络接口（HTTP + JSON）通信。
这样分工的好处是：计算再慢也不会卡住网页，业务数据再乱也不会污染计算代码。

| 分层 | 负责（管什么） | 不负责（不管什么） | 技术栈 |
| --- | --- | --- | --- |
| 前端 | 学生看到并操作的界面、晶体三维可视化、结果展示 | 不做数值计算；不直接访问数据库 | TypeScript + Vue |
| 数据管理 | 用户、任务、结构等数据的读写与存储；对外统一接口 | 不做数值计算 | Go + Gin + GORM |
| 数据处理 | 晶体结构预测、数值与几何计算等“重活” | 不直接面对浏览器；不直接读写业务数据库 | Python + FastAPI + NumPy |

> **技术名词速查**（首次出现，给个通俗解释）
>
> - **TypeScript / Vue**：Vue 是写网页界面的框架；TypeScript 是给 JavaScript 加上类型检查的版本，两者一起用来做前端。
> - **Go / Gin / GORM**：Go 是后端编程语言；Gin 是它的 Web 框架（负责接收网页请求、返回结果）；GORM 是它的数据库工具（让 Go 里的对象和数据库表自动互相转换，不必手写 SQL）。
> - **Python / FastAPI / NumPy**：Python 是科学计算常用语言；FastAPI 是它的 Web 框架（对外提供计算接口）；NumPy 是它的数值计算库（能快速处理大量数字）。

**请求流向（设计目标）**

```text
        学生浏览器
            │  操作界面
            ▼
     [ 前端 TypeScript + Vue ]
            │  HTTP / JSON
            ▼
[ 数据管理 Go + Gin + GORM ] ─── GORM ───► 数据库（用户 / 任务 / 结构）
            │  计算请求
            ▼
[ 数据处理 Python + FastAPI + NumPy ]
            │  计算结果（进度 / 结果 / 错误）
            ▼
      原路返回给前端展示
```

- 前端只与“数据管理”层通信；需要计算时，由数据管理层再请求“数据处理”层。
- 预测计算可能耗时较长，必须提供 **进度显示、取消入口、明确的结束状态**（具体做法见对应模块的 README）。
